# Hero Studios - Portfolio & Business Toolkit

Everything you need to grow Hero Studios: portfolio site, outreach templates, gig listings, and tools.

## Live Site

`https://herostudios.dev`

## Files

- `index.html` - Hero Studios portfolio (matches herostudios.dev design system)
- `style.css` - Hero Studios visual identity (purple/sea/sky, Sora/Inter fonts)
- `script.js` - Smooth scroll
- `templates/` - Minecraft product showcase templates
- `tools/invoice.html` - Invoice generator
- `outreach-messages.md` - Partnership & growth outreach templates
- `fiverr-gig.md` - Fiverr gig for Minecraft mod development
- `gumroad-listing.md` - Gumroad listing for selling themes/packs
- `email-templates/` - Ready-to-send outreach messages
- `business-card.html` - Printable QR business card
- `deploy.bat` - One-click GitHub push script

## Deploy

Double-click `deploy.bat` - it commits and pushes everything to GitHub.
Then enable GitHub Pages at: https://github.com/HeroBrokenBrine/herostudios-dev-studio/settings/pages

## Growth Strategy

1. Deploy portfolio → share on social media and Discord
2. Create Fiverr account → paste from `fiverr-gig.md` (Minecraft mod dev services)
3. Create Gumroad account → sell themes/packs from `gumroad-listing.md`
4. Send 5 outreach messages/day from `email-templates/`
5. Use `tools/invoice.html` to bill for custom work

## Tech Stack

- Pure HTML/CSS/JS - no build tools, instant deploy
- Fonts: Sora (display), Inter (body), JetBrains Mono (mono)
- Colors: Purple #8b5cf6, Sea #14b8a6, Sky #38bdf8
- Design: Oceanic dark (#050816), glass morphism, gradient accents
